プライバシーポリシー

最終更新日: 2026年11月13日

Hechizan(ノ山)(以下「当方」)が提供するアプリ(以下「本アプリ」)における、情報の取り扱いを説明します。本ページは、当方のすべてのアプリに共通する方針(第1〜7項)と、アプリごとの取り扱い(第8項)で構成しています。

1. 当方について

屋号: Hechizan(ノ山)
連絡先: info@hechizan.com

2. 基本方針

  • 必要最小限の情報のみを扱います。
  • アカウント登録を求めるアプリでは、その旨をアプリ内に表示します。登録が不要なアプリは、第8項に明記します。
  • ユーザーの個人情報を、販売することはありません。

3. 端末内で処理・保存される情報

写真、メモ、設定などのうち、アプリが端末内にのみ保存するものは、当方のサーバーには送信されません。どの情報が端末内に留まるかは、第8項のアプリごとの説明をご確認ください。

4. 広告

広告を表示するアプリでは、Google AdMob(Google Mobile Ads SDK)などの広告配信サービスを使用します。広告の配信・効果測定のため、これらの事業者が、端末の広告識別子、IPアドレス、端末・アプリの情報、広告の操作情報などを収集・利用する場合があります。広告を表示しないアプリは、第8項に明記します。

  • iOS のトラッキング許可: 広告識別子(IDFA)を使う場合は、Apple の「Appのトラッキング透明性」の確認画面で、許可をお尋ねします。選択は、「設定」>「プライバシーとセキュリティ」>「トラッキング」から、いつでも変更できます。
  • EEA・英国などでの同意: 必要な地域では、広告を要求する前に、同意フォーム(Google User Messaging Platform)を表示します。
  • Android の広告設定: 広告 ID は、端末の「設定」から、リセットまたは削除できます。

Google がアプリからの情報をどのように利用するかは、policies.google.com/technologies/partner-sites をご確認ください。

5. アプリ内課金・決済

アプリ内課金を提供するアプリでは、決済は Apple または Google が処理します。当方は、クレジットカード番号などの決済情報を、受け取ることも保存することもありません。

6. 子どもについて

本アプリは、子ども向けではなく、子どもの個人情報を意図的に収集することもありません。

7. 変更・お問い合わせ

本ポリシーは、変更されることがあります。最新の内容と日付は、常にこのページに表示します。お問い合わせは、お問い合わせページまでお願いします。

8. アプリごとの取り扱い

Snap Todo: Photo Checklist(iOS)

  • 扱う情報: ユーザーが撮影・選択した写真。文字の領域の検出と、チェックボックスの表示に使います。文字認識は、端末内で実行されます(Google ML Kit)。
  • 保存先: 写真と、保存したリストは、端末内のアプリ領域にのみ保存され、当方がアップロードすることはありません。
  • カメラ・写真ライブラリ: 写真の撮影・選択のためにのみ、許可を求めます。許可は、iOS の設定から、いつでも変更できます。
  • アカウント: 不要です。
  • 広告: Google AdMob のバナー広告を表示します(第4項)。写真やリストが、広告事業者に送信されることはありません。
  • ML Kit: 公開されているプライバシーマニフェストによると、個人を特定しない限定的な技術情報(デバイス識別子、性能・診断データなど)を収集する場合があります。詳細は、ML Kit data disclosure をご確認ください。
  • 個別のポリシーページ: Snap Todo のプライバシーポリシー(英語・日本語)

新しいアプリを公開する際は、このページに、アプリごとの取り扱いを追記します。
